# 明语星辰 · 轻量版

面向 Android 的占星排盘与资料助手。通过聊天整理资料、计算星盘、查找本地案例与记录，并阅读来源原文。

当前版本：**0.1.19（versionCode 20），公开试用版**。支持 Android 8.0 及以上的 arm64 设备。

## 安装与更新

[下载最新安装包 mingyu-stars.apk](https://github.com/CGM2026/mingyu-stars/releases/latest/download/mingyu-stars.apk) · [查看发布说明与对应源码](https://github.com/CGM2026/mingyu-stars/releases/latest)

0.1.8 起启动时会检查更新，由你选择是否下载；下载显示进度，校验完成后由你确认系统安装。已使用 0.1.5 至 0.1.7：在个人设置中点击检查更新即可升级。第一次安装，或从 0.1.4 及更早版本迁移：先下载安装包并覆盖安装一次，之后即可使用内置公网更新。你自行配置的其他来源保留，可在“高级来源”中清空并保存以恢复默认。

后续更新无须电脑运行服务、连接同一 Wi-Fi 或登录 GitHub；手机需要能访问 GitHub 及其下载服务。系统要求的安装来源授权和安装确认仍由你手动完成，不会静默安装。

## 使用

- 盘面工具栏的“案例档案”查看当前案例的备注、记录、分析和反馈，与侧栏全部档案列表独立；临时盘需主动存档后编辑。

- 存档默认关闭，可在输入框下方开启存档模式，或直接要求保存；独立档案页支持搜索、排序及批量删除。盘面底部已移除“保存工作页”和“保存为档案”按钮；输入区下方一行提供存档模式、附件与发送操作。
- 每张星盘以独立消息显示；左滑消息可引用，AI 消息长按可复制、引用或选择文字。相隔30分钟的新一段消息显示居中时间。
- 当前对话的模型与思考程度在“个人设置→模型与思考”调整，与新对话默认设置分别保存。
- 完整回复按段落、短句群或顶层列表项显示为连续气泡；支持片段与整次回复的复制/引用，后台保留原始完整回复，长内容保留完整阅读入口。
- 过程提示只显示与任务有关的动作、结果或阻碍，不提供内部思考展开入口；程序核验已提交输入，不等于模型已正确理解全部自然语言或任务已完成。
- 星盘设置和案例档案先显示分类入口；签点管理按类别逐级进入，单行列表支持长按拖动排序。长标题最多两行，地点仅显示经纬度，导出沿用盘面符号字体，长标题按导出宽度适配，避免静默裁字。
- 更多盘式提供本命、行运、返照、十年九月运、法达和黄道释放工作页。本命、行运与返照的调时组件保持完整日期时间单行；返照试调与精确返照分别标识。
- 手机界面使用系统黑体与柔和灰白底色。0.1.19 从安装包中移除闲置朝华、汇文字体；保留星座符号、公式和代码字体，原件及许可在对应源码中保留。
- 查询水逆结束等行星转顺、转逆时间，可直接用自然语言提问，由本地工具计算；探测不保存为星盘。

- 排盘时提供日期、准确时间和地点；需要当前时刻时直接说明“现在”，缺项或地点歧义时补充资料。
- 星盘与记录保存在本机；聊天左滑查看星盘，从盘页非交互区域右滑返回，盘轮、卡片与标签内的手势保留给对应操作。长内容可展开，完整回复仍可复制或选择文字。
- 点击星体查看详情；固定的详情卡不会被新点选覆盖，固定按钮原位变为关闭按钮。
- 长按历史对话展开紧凑菜单，可重命名、置顶、多选和删除；删除对话保留独立保存的案例、星盘与反馈。
- 自由聊天需要在个人设置中连接自己的 DeepSeek API。提交给模型的对话和必要资料会发送至该服务；本地排盘计算由应用执行。
- 导出案例、归档对话等操作以界面提供的入口为准。

这是持续完善的公开试用版。已有工具协议与本地计算检查不等于真实模型理解或真机完整体验验收；不同手机的启动、权限、键盘、分享和安装表现仍需实际使用反馈。

本次发布保留的验证缺口：Android 模拟器实时计算组件尚未完成验收；旧中断恢复提示仍含英文。网页计算或导出测试通过不等于 Android 实时计算已通过。
